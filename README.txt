AVINASH P - PORTFOLIO (HTML + CSS + JAVASCRIPT + BOOTSTRAP 5)

Files:
- index.html: portfolio content and Bootstrap CDN integration
- style.css: custom light-theme styling and additions for interactive controls
- script.js: typing effect, date/year, project filters, scroll-to-top, and form checks
- Add your existing avi.jpeg profile photo to this same folder.

Run:
1. Extract this ZIP.
2. Ensure avi.jpeg is in the same folder as index.html.
3. Open index.html in a browser, or use VS Code Live Server.

Bootstrap is loaded from jsDelivr, so an internet connection is needed for Bootstrap assets.
The contact form posts to the FormSubmit endpoint already present in the supplied HTML.
